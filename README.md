# Elegant Door POS System

A full-stack Point of Sale (POS) and Inventory Management System developed for **Elegant Doors**. The application streamlines sales operations by managing products, inventory, customers, orders, and invoices through a modern web interface, helping businesses track stock and process sales efficiently.

## ✨ Features

- Product and category management
- Inventory tracking
- Customer management
- Sales order processing
- Automatic stock updates
- Invoice generation
- Dashboard with business insights
- Role-based authentication
- Responsive user interface

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- React Router
- Axios

### Backend
- Node.js
- Express.js

### Database
- MySQL

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/junaid0x/elegant-door-pos.git
```

### Install dependencies

```bash
# Client
cd client
npm install

# Server
cd ../server
npm install
```

### Configure Environment Variables

Create a `.env` file inside the `server` directory and configure your database connection and application settings.

### Run the project

```bash
# Backend
npm run dev

# Frontend
npm run dev
```
